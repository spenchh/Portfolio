3×3 Systolic
MAC Array

A nine-processing-element array for 3×3 matrix multiplication, with signed 8-bit operands and 20-bit accumulators. I took the design through RTL verification, synthesis, and place-and-route.

Tools
Verilog, Xcelium, Genus, Innovus
Technology
Nangate 45 nm
Timing constraint
500 MHz
Post-route setup slack
+0.241 ns

Architecture

Nine processing elements form the 3×3 systolic array. Signed 8-bit input operands feed multiply-accumulate operations with 20-bit accumulators.

Verification

I verified all matrix outputs in RTL and gate-level simulation.

Physical implementation

I completed synthesis in Genus and place-and-route in Innovus. The routed design met the 500 MHz timing constraint with +0.241 ns setup slack and zero reported setup, hold, or DRC violations.
