Project 01 2026 to Present

FPGA-Based Field-Oriented Control

Architecting a motor-control accelerator on an Arty Zynq-7000 SoC for lightweight electric motors.

  • Develop SystemVerilog modules for 3PWM and 6PWM output, deadtime insertion, Hall-sector detection, speed estimation, ADC sample strobes, and reusable PI control.
  • Partition the control stack between ARM software for CAN, logging, calibration, and recovery and FPGA fabric for sensing, PWM, safety, and fixed-point control.
  • Research MATLAB, Simulink, and HDL Coder flows for Clarke and Park transforms, inverse Park, SVPWM, saturation, and anti-windup behavior.

Project 02 2026

Rear-Vision Camera and Display System

Designed and validated a low-latency rear-vision system for Northwestern's American Solar Challenge vehicle.

  • Built a sub-30 ms camera pipeline using a Pi Camera 3 Wide and CSI-to-HDMI extension hardware.
  • Automated headless startup and system recovery using Linux, Bash, and systemd.
  • Selected the architecture through a six-candidate trade study covering latency, field of view, EMI risk, cable length, reliability, integration complexity, and cost.

FPGA Beamforming Microphone Array

Designing a real-time multi-channel directional-audio system using fixed-point FPGA signal processing.
