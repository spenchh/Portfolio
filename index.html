Project 01

FPGA-Based Field-Oriented Control

June 2026 — Present

Architecting a motor-control accelerator on an Arty Zynq-7000 SoC: a fully pipelined Q1.15 current loop in FPGA fabric that takes raw three-phase ADC samples to complementary center-aligned PWM, with the protection path implemented in hardware rather than software.

  • Built the current loop as a valid-chained pipeline — ADC scaling, Clarke and Park transforms, dual PI regulators on the d and q axes, inverse Park, and alpha/beta-to-duty conversion — with every stage carrying its own *_valid strobe.
  • Implemented all control math in Q1.15 with saturating arithmetic at each stage: products widen to full precision, shift back by 15 fractional bits, then clamp to the 16-bit range instead of wrapping.
  • Wrote a quarter-wave sine/cosine LUT that resolves a 16-bit electrical angle using a 64-entry quarter table, deriving quadrant and mirrored index from the angle's upper bits rather than storing a full period.
  • Generated complementary three-phase PWM from a center-aligned counter with programmable non-overlap (deadtime) ticks, plus a configuration_error output that rejects any period/deadtime combination where the high and low sides could overlap.
  • Enforced safety in fabric: over-current, phase-imbalance, and bus/phase voltage monitors feed a latching disable controller that gates PWM and holds the fault until an explicit clear, exposing a status code for the cause.
  • Verified each block with self-checking testbenches that assert on failure — including checks that HI/LO pairs never overlap, that inhibit truly shuts outputs off, and that an invalid duty raises the configuration error.

Project 02

3×3 Systolic MAC Array — RTL to Place-and-Route

ASIC flow project

A 3×3 systolic multiply-accumulate array taken through a complete digital design flow — RTL, functional verification, synthesis, and place-and-route — to learn what actually governs a design once it leaves simulation.

  • Designed the array for signed 8-bit operands with 20-bit accumulated outputs, sized so intermediate sums cannot overflow across the accumulation chain.
  • Verified functional behavior in Cadence Xcelium against expected products and accumulation results.
  • Synthesized with Cadence Genus under SDC timing constraints, then reviewed setup and hold analysis alongside area and power reports.
  • Completed place-and-route in Cadence Innovus to a DRC-clean routed layout.
