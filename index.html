CSI / HDMI 60 FPS
Project 01 2026

Rear-Vision Camera

Built a real-time rear-vision system for Northwestern's 2026 solar car using a Pi Camera Module 3 Wide with CSI to HDMI extensions.

  • Achieved sub-40ms latency at 60 fps over 3 meters.
  • Benchmarked six platforms against automotive-grade GMSL2 and FPD-Link III standards.
  • Developed an interactive HTML dashboard for performance data using Chart.js.
Role: Embedded Systems Team: NUSolar

Project 02 2026

FPGA FOC Control

Implementing Field-Oriented Control in Verilog HDL on an FPGA to improve lightweight motor control for the NUSolar Mitsuba M2096.

  • Maximizing PWM switching frequency to reduce current ripple in low-inductance motors.
  • Benchmarking hardware-accelerated motor control against commercial controllers.
  • Designing a custom PCB for FPGA-based control and integration.
Role: Research / Hardware Focus: Motor Control

Project 03 2026

FPGA Beamforming Array

Building an FPGA beamforming microphone array with real-time spatial tracking for focused audio capture.

  • Combines camera-based face tracking with FPGA signal processing.
  • Locates and follows a sound source in real time.
  • Coherently sums microphone inputs into spatially focused audio.
Role: FPGA / DSP Focus: Real-Time Audio
