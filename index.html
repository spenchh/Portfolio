Project 01

FPGA-Based Field-Oriented Control

June 2026 to Present

Architecting a motor-control accelerator on an Arty Zynq-7000 SoC, with real-time control and safety functions implemented in FPGA fabric and system management handled by ARM software.

  • Develop SystemVerilog modules for 3PWM and 6PWM output, deadtime insertion, Hall-sector detection, speed estimation, ADC sample timing, and reusable PI control.
  • Partition CAN, logging, calibration, and recovery into ARM software while keeping PWM, sensing, safety, and fixed-point control in FPGA logic.
  • Research MATLAB, Simulink, and HDL Coder workflows for Clarke and Park transforms, SVPWM, saturation, and anti-windup behavior.
Platform Arty Zynq-7000 SoC
Languages SystemVerilog, Python, Bash
Core concepts AXI-Lite, fixed-point arithmetic, PWM, FOC, fault handling
Tools Vivado, MATLAB, Simulink, HDL Coder
Project 02

FPGA Beamforming Microphone Array

June 2026 to Present

Designing a fixed-point delay-and-sum beamforming pipeline for real-time, multi-channel directional audio processing.

  • Implement the beamforming datapath in Verilog for deterministic real-time processing.
  • Integrate camera-based face tracking to steer the FPGA DSP pipeline toward a moving source.
  • Evaluate latency, phase alignment, numerical precision, and FPGA resource tradeoffs.
Focus Real-time audio DSP
Language Verilog
Core concepts Fixed-point DSP, delay-and-sum beamforming, pipelining
Integration Camera tracking and FPGA signal processing
Project 03

Rear-Vision Camera and Display System

March 2026 to June 2026

Designed and validated a low-latency rear-vision system for Northwestern’s 2026 American Solar Challenge vehicle.

  • Built a sub-30 ms video pipeline using a Pi Camera 3 Wide and CSI-to-HDMI extension hardware.
  • Automated headless startup and recovery with Linux, Bash, and systemd.
  • Selected the final design through a six-candidate trade study covering latency, field of view, EMI risk, reliability, integration complexity, and cost.
Platform Raspberry Pi and Pi Camera 3 Wide
Performance Sub-30 ms end-to-end latency
Software Linux, Bash, systemd
Engineering process Architecture trade study and hardware validation
