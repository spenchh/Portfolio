10GbE FPGA Tick-to-Trade Datapath

Independent research / active

A simulation-first FPGA datapath for low-latency market-data processing and order-decision logic. The trading workload is a forcing function for the real subject: deterministic networking, streaming packet parsing, fixed-point decision logic, and risk checks enforced in hardware rather than software.

A SystemVerilog pipeline runs from UDP/IP parsing through market-data decoding, symbol and book state, decision logic, a hardware risk gate, and order and cancel encoding. Python and cocotb drive packet generation, golden-model comparison, randomized tests, and scoreboard checks. C++20 host tools handle replay, control, and logging.

Status. Active development. No latency has been measured, no timing closed, no hardware run, and nothing connected to live trading. Self-checking tests, timing reports, latency measurements, debug captures, and a hardware demo are targets for this project, not results.
